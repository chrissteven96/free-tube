## ✨ Características Principal

* ⚡ **Descargas Rápidas:** Optimizado para procesar descargas de video y extracción de audio en alta calidad.
* 🎨 **Interfaz Moderna e Intuitiva:** Desarrollado con React y Electron para ofrecer una experiencia fluida y reactiva.
* 🖥️ **Multiplataforma:** Construido sobre Electron Framework para ejecución nativa en escritorio.
* 🎵 **Soporte de Formatos:** Descarga fácil de contenido multimedia en múltiples formatos.
* 🆓 **100% Código Abierto:** Sin rastreadores ni publicidad integrada.

## 🚀 Instalación y Uso

1. Ve a la sección de **[Releases]([https://github.com/chrissteven96/free-tube/releases/latest](https://github.com/chrissteven96/free-tube/releases/tag/v1.0.0))**.
2. Descarga el archivo ejecutable `freeTube-by-ChristoTech.exe`.
3. Ejecuta el instalador y abre la aplicación.
4. ¡Pega la URL de tu video o audio preferido y comienza la descarga!

---

## 🛠️ Tecnologías Utilizadas

* **[Electron](https://www.electronjs.org/)** — Framework para desarrollo de aplicaciones de escritorio.
* **[React](https://react.dev/)** — Librería de interfaz de usuario.
* **[Electron Forge](https://www.electronforge.io/)** — Herramienta completa para empaquetar y publicar apps de Electron.
* **[yt-dlp](https://github.com/yt-dlp/yt-dlp)** — Motor principal de descarga y procesamiento de contenido.

## 💻 Desarrollo Local

Si deseas clonar el proyecto y ejecutarlo localmente en tu entorno de desarrollo:

```bash
# 1. Clonar el repositorio
git clone [https://github.com/chrissteven96/free-tube.git](https://github.com/chrissteven96/free-tube.git)

# 2. Entrar al directorio
cd free-tube

# 3. Instalar dependencias
npm install

# 4. Iniciar la aplicación en modo desarrollo
npx electron-forge start

# 5. Compilar el Descargador
npm start
